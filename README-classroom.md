# ฟีเจอร์ "เช็คคะแนนตกเกณฑ์ ม.6/7" — คู่มือติดตั้ง

ฟีเจอร์นี้แยกไฟล์ออกมาต่างหากทั้งหมด **ไม่แตะไฟล์เดิมของเพื่อนเลย** (server.js เดิม, wellbeing.js,
aiClassifier.js ฯลฯ ไม่ถูกแก้ไข) ปลอดภัย เอาไปวางทับได้เลยโดยไม่กระทบของเดิม

ทดสอบแล้วในเครื่อง (จำลอง server จริง + อัปโหลดไฟล์ Excel จริง) ทำงานถูกต้องครบทุกจุด:
- อ่านไฟล์ Excel จริงได้ถูกต้อง
- จับคู่นักเรียนในห้องถูกต้อง + ข้ามคนที่ไม่อยู่ในห้องอัตโนมัติ
- คำนวณ % และสถานะ ตก/ปกติ ถูกต้องตามเกณฑ์ที่กรอก
- บันทึกลงไฟล์ + ไม่ crash แม้ยังไม่ตั้งค่า LINE userId ของครู

## ไฟล์ที่ต้องเพิ่มเข้า repo (คัดลอกทั้งโฟลเดอร์ไปวางในตำแหน่งเดียวกัน)

```
routes/classroom.js              <- ใหม่ทั้งหมด
lib/excelParser.js               <- ใหม่ทั้งหมด
lib/gradeChecker.js              <- ใหม่ทั้งหมด
lib/notifyTeachers.js            <- ใหม่ทั้งหมด
data/classroom-roster.json       <- ใหม่ทั้งหมด (25 คน ม.6/7)
data/classroom-scores.json       <- ใหม่ทั้งหมด (เริ่มต้นเป็น [])
data/classroom-teachers.json     <- ใหม่ทั้งหมด (เริ่มต้นเป็น {})
public/classroom.html            <- ใหม่ทั้งหมด
```

## ขั้นตอนติดตั้ง

**1. เพิ่ม dependencies ใน `package.json` เดิม**

เปิด `package.json` ที่ repo อยู่แล้ว เพิ่ม 2 บรรทัดนี้ในส่วน `"dependencies"`:
```json
"multer": "^2.2.0",
"xlsx": "^0.18.5"
```
(ถ้ามี `@line/bot-sdk` อยู่แล้วไม่ต้องเพิ่มซ้ำ ใช้ตัวเดิมได้เลย)

**2. อัปโหลดไฟล์ทั้ง 8 ไฟล์ข้างบนเข้า repo**
ใช้วิธีเดิม (Add file → Upload files → ลากทั้งโฟลเดอร์) — GitHub จะสร้างโฟลเดอร์ `routes/` ให้อัตโนมัติเพราะยังไม่เคยมี

**3. แก้ `server.js` เดิม เพิ่มแค่ 2 บรรทัด**

หาบริเวณที่เพื่อน `require` ไฟล์อื่นๆ ไว้ตอนต้นไฟล์ (เช่น `const line = require("@line/bot-sdk")`) เพิ่มบรรทัดนี้ต่อจากนั้น:
```js
const classroomRouter = require("./routes/classroom");
```

แล้วหาบริเวณที่มี `app.use(express.static(...))` หรือ `app.get("/", ...)` เพิ่มบรรทัดนี้ไว้ **ก่อน** `app.listen(...)`:
```js
app.use("/classroom", classroomRouter);
```

**4. Commit + push → Render deploy อัตโนมัติ**

## วิธีใช้งาน

1. เปิด `https://line-risk-bot.onrender.com/classroom`
2. ตั้งค่า LINE userId ของครูแต่ละคน (ครูต้องแอด LINE OA เป็นเพื่อนก่อน แล้วดู userId จาก Render Logs วิธีเดียวกับที่เคยทำตอนตั้ง `TEACHER_LINE_USER_ID`)
3. อัปโหลด Excel คะแนน — ไฟล์ต้องมีคอลัมน์:
   - `รหัสนักเรียน` (หรือ `ชื่อ-นามสกุล`)
   - `คะแนน`
4. กรอกวิชา / บท / คะแนนเต็ม / เกณฑ์ % ในหน้าเว็บตอนอัปโหลด (ไม่ต้องใส่ในไฟล์ Excel)
5. ระบบคำนวณอัตโนมัติ + ถ้ามีคนตกเกณฑ์ จะ push LINE ไปหาครูวิชานั้น + ครูประจำชั้นทันที

## ข้อจำกัดที่ควรรู้ (เหมาะกับ prototype/demo)

- ข้อมูลเก็บเป็นไฟล์ JSON ธรรมดา ไม่ใช่ database จริง — ถ้า Render restart/redeploy ข้อมูลคะแนนที่เคยอัปโหลดจะหาย (userId ครูก็หายด้วย ต้องตั้งใหม่)
- ไม่มีระบบ login — ใครมีลิงก์ `/classroom` ก็เข้าอัปโหลด/แก้ข้อมูลได้หมด เหมาะสำหรับ demo ในทีมเท่านั้น ไม่ควรเผยแพร่ลิงก์สาธารณะ
- รองรับแค่ 1 ห้องเรียน (ม.6/7) ตามที่ตั้งใจไว้ ถ้าจะขยายหลายห้องต้องปรับโครงสร้างข้อมูลเพิ่ม
